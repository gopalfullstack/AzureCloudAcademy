# CloudSaver AI – 60-Day Hands-on Programme

**Azure Cloud Academy | 8 modules | 60 days | 210 hours**

Build an AI-powered enterprise FinOps prototype from the ground up. The programme combines Python, Azure data engineering, FinOps analytics, Kubernetes/AKS, generative AI, RAG, AI agents, forecasting, backend engineering, Terraform, CI/CD, security and testing.

## Daily learning format

- 45 minutes: concept and technical explanation
- 60 minutes: guided hands-on lab
- 75 minutes: CloudSaver AI product development
- 20 minutes: testing and troubleshooting
- 10 minutes: notes and Git commit

**Total: 210 minutes (3.5 hours) per day.**

## Final programme outcome

Learners work towards a demonstrable prototype with Azure cost ingestion, FinOps analytics, AKS workload cost intelligence, a grounded FinOps Copilot, anomaly detection, cost forecasting, recommendations, approval history and audit logging.

## Important lab and safety guidance

- Start with synthetic billing data and local development environments.
- Use an Azure subscription only where a lab requires it; set budgets and alerts before provisioning paid services.
- Never commit credentials, tokens, connection strings or customer billing data to Git.
- Use read-only Azure access for the MVP.
- The language model must not calculate authoritative bills or hold broad Azure credentials.
- No autonomous production changes or resource deletion are part of this programme.
- Validate service availability, API versions, regional support and pricing before deployment.
