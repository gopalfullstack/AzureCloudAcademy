# Day 1 – Python Setup and Fundamentals

**Module:** 01 – Python, Git and Software Engineering  
**Duration:** 3.5 hours

## Learning objective

Set up a working Python environment and write your first small cloud-cost calculator.

## Topics to learn

1. Understand Python, the interpreter and how Python is used in cloud engineering.
2. Install Python and Visual Studio Code; install the Python extension.
3. Run a script from VS Code and the terminal.
4. Learn variables, naming conventions, comments and basic types: str, int, float and bool.
5. Use type conversion, arithmetic and comparison operators.
6. Read user input, print output and format values with f-strings.
7. Use Boolean logic and if/elif/else conditions.

## Where to learn

- [Install Python](https://www.python.org/downloads/)
- [Install Visual Studio Code](https://code.visualstudio.com/)
- [Python tutorial – introduction](https://docs.python.org/3/tutorial/introduction.html)
- [LearnPython – interactive exercises](https://www.learnpython.org/)

## Hands-on practical lab

Build a command-line calculator. Ask the user for a resource name, hourly rate and number of running hours. Validate that the numbers are positive, calculate an illustrative cost and print a formatted summary. Explain that this is a learning estimate, not an Azure invoice calculation.

## Expected deliverables

- [ ] day01_cost_calculator.py
- [ ] Screenshot or terminal output showing a successful run

## Completion checklist

- [ ] Python is installed and runs from the terminal.
- [ ] The script accepts input and converts numeric values safely.
- [ ] The calculator prints the resource name and calculated cost.
- [ ] Invalid numeric input is handled clearly.
