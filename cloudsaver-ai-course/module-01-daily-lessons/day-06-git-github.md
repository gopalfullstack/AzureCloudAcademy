# Day 6 – Git and GitHub

**Module:** 01 – Python, Git and Software Engineering  
**Duration:** 3.5 hours

## Learning objective

Track project changes and collaborate using a basic GitHub workflow.

## Topics to learn

1. Understand Git versus GitHub.
2. Create a GitHub account and repository.
3. Install and configure Git.
4. Initialise or clone a repository.
5. Understand working tree, staging area and commit history.
6. Use git status, add, diff, commit, pull and push.
7. Create branches and merge changes.
8. Resolve a simple merge conflict.
9. Create a pull request.
10. Write a README and configure .gitignore.
11. Never commit credentials or confidential billing data.

## Where to learn

- [GitHub Skills – Introduction to GitHub](https://github.com/skills/introduction-to-github)
- [GitHub Skills – Introduction to Git](https://github.com/skills/introduction-to-git)
- [GitHub Docs – Git basics](https://docs.github.com/en/get-started/git-basics)
- [Pro Git book](https://git-scm.com/book/en/v2/Getting-Started-About-Version-Control)

## Hands-on practical lab

Create a repository named cloudsaver-billing-processor. Add the previous exercises, create a feature branch, change a file, commit and push it, then open a pull request. Add a README and .gitignore. Use synthetic data only.

## Expected deliverables

- [ ] GitHub repository URL
- [ ] README.md
- [ ] A feature branch and pull request
- [ ] A suitable .gitignore

## Completion checklist

- [ ] Repository contains organised source files.
- [ ] Commit messages describe the changes.
- [ ] A branch and pull request are demonstrated.
- [ ] Secrets and local environment files are excluded.
