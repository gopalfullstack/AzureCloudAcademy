# Module 03 – FinOps Analytics and Database Engineering

**Schedule:** Days 16–22  
**Purpose:** Turn curated billing records into trusted cost intelligence.  
**Outcome:** A PostgreSQL cost model, reusable analytics queries and a Power BI dashboard.

## Learning outcomes

Learners understand FinOps practices, relational data modelling, SQL, PostgreSQL, cost allocation and dashboard design.

## Daily class structure

- 45 minutes: concepts and explanation
- 45 minutes: instructor demonstration
- 60 minutes: guided implementation
- 45 minutes: independent practical lab
- 15 minutes: review and questions

**Total: 3.5 hours per day.** Each daily guide includes detailed topics, learning links, a hands-on lab, expected deliverables and a completion checklist.
