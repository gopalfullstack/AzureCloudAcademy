# Day 2 – Conditions, Loops, Collections and Functions

**Module:** 01 – Python, Git and Software Engineering  
**Duration:** 3.5 hours

## Learning objective

Represent multiple cloud resources in Python and create reusable cost calculations.

## Topics to learn

1. Use if/elif/else for decisions.
2. Use for and while loops; understand break, continue and pass.
3. Create and modify lists, tuples, sets and dictionaries.
4. Use indexing, slicing and iterate through collections.
5. Use list and dictionary comprehensions.
6. Write functions with parameters, return values and default arguments.
7. Separate reusable logic into functions.

## Where to learn

- [Python control flow](https://docs.python.org/3/tutorial/controlflow.html)
- [Python data structures](https://docs.python.org/3/tutorial/datastructures.html)
- [Defining functions](https://docs.python.org/3/tutorial/controlflow.html#defining-functions)
- [LearnPython – interactive exercises](https://www.learnpython.org/)

## Hands-on practical lab

Create a list of resource dictionaries containing name, service and monthly cost. Write functions to calculate total spend, find the highest-cost resource and return resources above a configurable threshold. Print a clear report.

## Expected deliverables

- [ ] day02_resources_report.py
- [ ] A sample resource list and terminal report

## Completion checklist

- [ ] Resources are stored in dictionaries inside a list.
- [ ] At least three reusable functions are implemented.
- [ ] Total and highest resource costs are correct.
- [ ] A threshold can be changed without rewriting the calculation.
