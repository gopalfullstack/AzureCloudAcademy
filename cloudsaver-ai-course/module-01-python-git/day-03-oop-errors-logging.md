# Day 3 – OOP, Files, Exceptions and Logging

**Module:** 01 – Python, Git and Software Engineering  
**Duration:** 3.5 hours

## Learning objective

Organise code into reusable components and make the program safer to operate.

## Topics to learn

1. Import modules and organise Python files.
2. Understand classes, objects, constructors, attributes and methods.
3. Use encapsulation and basic inheritance; understand composition.
4. Read and write text files using context managers.
5. Handle exceptions with try/except/else/finally.
6. Raise exceptions for invalid input.
7. Use logging levels DEBUG, INFO, WARNING and ERROR.

## Where to learn

- [Python classes](https://docs.python.org/3/tutorial/classes.html)
- [Errors and exceptions](https://docs.python.org/3/tutorial/errors.html)
- [File input and output](https://docs.python.org/3/tutorial/inputoutput.html)
- [Logging HOWTO](https://docs.python.org/3/howto/logging.html)

## Hands-on practical lab

Create an AzureResource class with resource name, resource type and monthly cost. Add a method for annualised cost. Validate cost values, reject invalid data and write processing events and errors to a log file.

## Expected deliverables

- [ ] day03_azure_resource.py
- [ ] A log file generated by the program

## Completion checklist

- [ ] A class can be instantiated with resource details.
- [ ] Methods return correct monthly and annualised costs.
- [ ] Invalid costs are rejected with a helpful message.
- [ ] The program writes useful log entries.
