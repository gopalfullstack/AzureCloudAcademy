# Module 02 – Microsoft Azure Cloud and Data Engineering

**Schedule:** Days 8–15  
**Purpose:** Build a reliable Azure billing-data ingestion path.  
**Outcome:** An automated pipeline that lands, validates and curates cost-export files.

## Learning outcomes

Learners understand Azure resource organisation, Cost Management exports, ADLS Gen2, Event Grid, Azure Functions and data-quality controls.

## Daily class structure

- 45 minutes: concepts and explanation
- 45 minutes: instructor demonstration
- 60 minutes: guided implementation
- 45 minutes: independent practical lab
- 15 minutes: review and questions

**Total: 3.5 hours per day.** Each daily guide includes detailed topics, learning links, a hands-on lab, expected deliverables and a completion checklist.
