# Day 58 – Dashboard and End-to-End Integration

**Module:** 08 – Security, Testing, Integration and Final Product Development  
**Programme day:** 58  
**Duration:** 3.5 hours

## Learning objective

Connect the product interface to backend APIs and demonstrate key user journeys.

## Detailed topics

1. Frontend/backend integration
2. authenticated API calls
3. cost KPI cards
4. subscription/service filters
5. AKS node/workload views
6. Databricks cost view
7. anomaly list/detail
8. forecast chart and uncertainty
9. Copilot UI
10. recommendation cards
11. approval history
12. loading/empty/error states
13. data freshness.

## Where to learn

- [Power BI guidance](https://learn.microsoft.com/en-us/power-bi/)
- [FastAPI OpenAPI](https://fastapi.tiangolo.com/features/)
- [Microsoft identity platform](https://learn.microsoft.com/en-us/entra/identity-platform/v2-overview)

## Hands-on practical lab

Connect the dashboard to the deployed backend. Demonstrate cost investigation, AKS workload review, anomaly drill-down, Copilot evidence and recommendation approval using sample data. Test loading, empty and API error states.

## Expected deliverables

- [ ] Integrated application
- [ ] user journey script
- [ ] screenshots/demo
- [ ] integration issue list.

## Completion checklist

- [ ] Dashboard reflects API data
- [ ] scope and identity are respected
- [ ] loading/error states are clear
- [ ] values show period/currency/freshness.

**Product safety:** Use synthetic or explicitly authorised data. Keep production write actions disabled in the training MVP. Record limitations and require human approval for any future operational change.
