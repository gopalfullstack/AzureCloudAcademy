# Day 60 – Final Demonstration and Founder Review

**Module:** 08 – Security, Testing, Integration and Final Product Development  
**Programme day:** 60  
**Duration:** 3.5 hours

## Learning objective

Demonstrate the integrated CloudSaver AI prototype and recommend the next product decision.

## Detailed topics

1. End-to-end demo preparation
2. sample data and scenario
3. ingestion
4. reconciliation
5. dashboard
6. AKS allocation assumptions
7. Databricks sample analysis
8. Copilot grounding
9. anomaly and forecast evaluation
10. recommendations
11. approval workflow
12. security posture
13. Azure cost
14. customer problem validation
15. go/revise/pause/stop criteria.

## Where to learn

- [FinOps Framework](https://www.finops.org/framework/)
- [Azure Well-Architected Framework](https://learn.microsoft.com/en-us/azure/well-architected/)
- [Azure Cost Management](https://learn.microsoft.com/en-us/azure/cost-management-billing/costs/overview-cost-management)

## Hands-on practical lab

Run a scripted demo from source data to final recommendation. Present evidence for cost accuracy, AKS allocation assumptions, AI grounding, model evaluation, security and operating cost. End with a written go/revise/pause/stop recommendation.

## Expected deliverables

- [ ] Demo recording/slides
- [ ] final repo
- [ ] test and reconciliation evidence
- [ ] cost summary
- [ ] product decision memo.

## Completion checklist

- [ ] All core flows are reproducible
- [ ] claims are supported by evidence
- [ ] limitations are explicit
- [ ] no autonomous production write action
- [ ] next step is justified by user value and delivery economics.

| Activity | Time |

**Product safety:** Use synthetic or explicitly authorised data. Keep production write actions disabled in the training MVP. Record limitations and require human approval for any future operational change.
