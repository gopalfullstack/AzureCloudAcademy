# Day 41 – Machine Learning Foundations for FinOps

**Module:** 06 – AI Agents, Anomaly Detection and Predictive FinOps  
**Programme day:** 41  
**Duration:** 3.5 hours

## Learning objective

Compare simple statistical rules with a basic ML model on prepared cost features.

## Detailed topics

1. Supervised versus unsupervised learning
2. features and labels
3. train/test split
4. feature engineering
5. leakage
6. scaling
7. baseline models
8. classification and regression
9. precision/recall/F1
10. overfitting
11. cross-validation concepts
12. drift
13. interpretability
14. when rules are preferable.

## Where to learn

- [Scikit-learn getting started](https://scikit-learn.org/stable/getting_started.html)
- [Model evaluation](https://scikit-learn.org/stable/modules/model_evaluation.html)
- [Common pitfalls and leakage](https://scikit-learn.org/stable/common_pitfalls.html)

## Hands-on practical lab

Use a prepared synthetic dataset to classify anomalous days or estimate cost. Split training and test periods correctly, compare a simple rule with a basic model and explain which is more suitable.

## Expected deliverables

- [ ] Notebook/script
- [ ] train/test methodology
- [ ] model metrics
- [ ] comparison and limitations note.

## Completion checklist

- [ ] No future data leakage
- [ ] model is compared with baseline
- [ ] evaluation uses held-out data
- [ ] limitations and maintenance needs are explained.
