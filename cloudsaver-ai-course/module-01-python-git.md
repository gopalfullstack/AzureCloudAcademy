# Module 01 – Python, Git and Software Engineering

**Programme:** CloudSaver AI – Azure Cloud Academy  
**Duration:** 7 days | **3.5 hours per day** | **24.5 hours total**

Welcome to Module 1. Each day has its own learning guide, resources, practical lab, deliverables and completion checklist.

| Day | Learning guide | Main outcome |

## Daily class timetable

| Activity | Time |
|---|---:|
| Concepts and explanation | 45 minutes |

| **Total** | **3 hours 30 minutes** |

## Module completion

Learners complete all seven daily labs and submit the final CloudSaver Billing Processor repository. Assessment:

- Daily coding exercises: 30%
- Practical labs: 30%
- GitHub workflow and documentation: 10%
- Final project: 30%

**Instructor note:** This is an intensive seven-day foundation. Complete beginners may need 10–14 days. Use synthetic billing data in this module; real Azure account integration and credential handling are covered later with appropriate identity and security controls.
