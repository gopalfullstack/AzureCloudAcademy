# Day 22 – Power BI Cost Intelligence Dashboard

**Module:** 03 – FinOps Analytics and Database Engineering  
**Programme day:** 22  
**Duration:** 3.5 hours

## Learning objective

Present validated cost data in an interactive dashboard for engineering and finance.

## Detailed topics

1. Power BI Desktop
2. PostgreSQL connector
3. Power Query
4. star schema relationships
5. DAX measures
6. calculated columns versus measures
7. KPI cards
8. trend charts
9. matrix and tables
10. slicers
11. drill-through
12. tooltips
13. refresh
14. accessibility
15. data freshness labels
16. dashboard storytelling.

## Where to learn

- [Power BI learning](https://learn.microsoft.com/en-us/training/powerplatform/power-bi/)
- [Power BI star schema](https://learn.microsoft.com/en-us/power-bi/guidance/star-schema)
- [DAX documentation](https://learn.microsoft.com/en-us/dax/)

## Hands-on practical lab

Build a CloudSaver dashboard with total spend, spend trend, subscription/service breakdown, top resources, budget variance, unallocated costs and date/scope filters. Display currency, period and refresh timestamp.

## Expected deliverables

- [ ] Power BI PBIX
- [ ] dashboard screenshots
- [ ] DAX measure list
- [ ] data refresh notes.

## Completion checklist

- [ ] KPI totals reconcile to SQL
- [ ] slicers work
- [ ] currency and period are clear
- [ ] charts avoid misleading scales
- [ ] missing data is disclosed.
