# Day 31 – Generative AI and LLM Fundamentals

**Module:** 05 – Generative AI, Microsoft Foundry and RAG  
**Programme day:** 31  
**Duration:** 3.5 hours

## Learning objective

Understand how LLM applications work and where they fit in a FinOps product.

## Detailed topics

1. AI/ML/deep learning overview
2. generative AI
3. LLMs and transformer intuition
4. tokens and tokenisation
5. context windows
6. inference
7. temperature and parameters
8. system/user messages
9. structured output
10. hallucinations
11. model limitations
12. responsible AI and privacy.

## Where to learn

- [Microsoft Learn – Generative AI](https://learn.microsoft.com/en-us/training/paths/introduction-generative-ai/)
- [Azure OpenAI concepts](https://learn.microsoft.com/en-us/azure/ai-services/openai/concepts/models)
- [Responsible AI](https://learn.microsoft.com/en-us/azure/machine-learning/concept-responsible-ai)

## Hands-on practical lab

Run controlled prompts against an approved model or instructor-provided playground. Compare concise, detailed and structured responses to a FinOps question. Record unsupported claims and token/context effects.

## Expected deliverables

- [ ] Prompt experiment sheet
- [ ] model response comparison
- [ ] list of hallucination risks.

## Completion checklist

- [ ] Can explain tokens and context
- [ ] recognises hallucinations
- [ ] distinguishes generated explanation from validated billing calculations
- [ ] avoids sending sensitive data.

## Suggested session timetable

| Activity | Time |
|---|---:|
| Concepts and architecture | 45 min |
| Instructor demonstration | 45 min |
| Guided implementation | 60 min |
| Independent lab and evaluation | 45 min |
| Review and questions | 15 min |
| **Total** | **3.5 hours** |

**AI safety:** Use approved non-sensitive sample data. Treat retrieved documents and user prompts as untrusted inputs. The model must not invent authoritative cost numbers or have unrestricted access to Azure resources.
