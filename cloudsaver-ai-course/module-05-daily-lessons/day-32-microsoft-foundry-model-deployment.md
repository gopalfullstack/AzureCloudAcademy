# Day 32 – Microsoft Foundry and Model Deployment

**Module:** 05 – Generative AI, Microsoft Foundry and RAG  
**Programme day:** 32  
**Duration:** 3.5 hours

## Learning objective

Deploy an available model and call it from a Python application.

## Detailed topics

1. Foundry project/resource concepts
2. model catalogue
3. model selection
4. deployment and endpoint
5. authentication
6. SDK/REST calls
7. request/response format
8. system instructions
9. inference parameters
10. token usage
11. quotas and rate limits
12. model availability by region
13. monitoring and cost awareness.

## Where to learn

- [Microsoft Foundry documentation](https://learn.microsoft.com/en-us/azure/ai-foundry/)
- [Model catalog](https://learn.microsoft.com/en-us/azure/ai-foundry/concepts/foundry-models-overview)
- [Python SDK](https://learn.microsoft.com/en-us/azure/ai-foundry/quickstarts/get-started-code)

## Hands-on practical lab

Using an approved Azure subscription and budget, deploy an available model, store endpoint configuration securely, call it from Python and handle authentication, quota and response errors. Check current portal and SDK instructions before class.

## Expected deliverables

- [ ] Deployment notes
- [ ] Python client
- [ ] configuration template without secrets
- [ ] test output and cost/usage notes.

## Completion checklist

- [ ] Model endpoint works
- [ ] credentials are not hard-coded
- [ ] errors and quotas are handled
- [ ] deployment region and model version are recorded.
